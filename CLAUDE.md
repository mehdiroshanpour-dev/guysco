# Guyscompany

Collaboration web app for a 4-person team (2D dashboard + first-person 3D virtual office).

- Full design: `SPEC-FINAL.md`. Build steps: `BUILD-INSTRUCTIONS.md`. Read both before writing code.
- Stack: TypeScript, Next.js (App Router), React Three Fiber, Tailwind, next-intl, Supabase, Drizzle, WebRTC. Free tiers only (Vercel Hobby, Supabase free).
- Code and identifiers in English; UI text in Persian (RTL) and English (LTR).
- Everything must be responsive (phone and desktop).
- Characters: select one of 20 premade characters only; no character customization screen.
- Do not guess open items in the spec; ask the owner.
